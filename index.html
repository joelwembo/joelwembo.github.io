Key Projects & Research

Durable Agentic Workflows

Developing resilient AI agents using Temporal.io to manage long-running stateful executions. By combining LangChain with Temporal, I ensure that complex AI reasoning tasks are fault-tolerant and human-in-the-loop ready.

Fine-Tuned RAG Cloud Recommendation Model for Enterprise Software Provisioning

Developed a sophisticated Cloud Agentic Model using PyTorch and Hugging Face (Mistral / Gemini) designed to process large-scale datasets for enterprise deployment. This project optimizes the transition from unstructured documents to structured data through advanced retrieval and cost-efficient inference.

  • Model Orchestration: Hugging Face transformers and PyTorch for fine-tuning Mistral-7B as the core reasoning engine.
  • Cloud Agent Logic: Cloud-native agent capable of Cloud Reconnaissance to dynamically allocate resources, reducing latency and operational overhead.
  • Search & Ranking: Hybrid Search (Vector + Keyword) paired with a Cross-Encoder re-ranker for highest accuracy in document retrieval.
  • Cost Efficiency: Gemini and custom quantization techniques to reduce API token consumption without sacrificing precision.
